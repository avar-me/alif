# alif.avar.me

Таблицы и материалы по аварским алфавитам и скриптам: кириллица, аджам, латиница и системы транслитерации.

Сайт: <https://alif.avar.me>

Страница перенесена с [en.avar.me/alphabet.html](https://en.avar.me/alphabet.html).

## Данные

Исходная таблица — [`data/alphabet.csv`](data/alphabet.csv). После правок пересоберите страницу:

```bash
python3 build/build.py
```

Локальный просмотр:

```bash
python3 -m http.server 8000
```
