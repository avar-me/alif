Примечания

  • avar.me — практическая латиница, используемая на проектах avar.me
  • Scientific — академический стандарт транслитерации кавказских языков
  • Typing — ASCII-транслитерация для удобного ввода без диакритики
  • 1932 — исторический латинский алфавит аварского языка (1928–1938 гг.)
  • Google — вариант машинного перевода Google Translate (— = не зафиксировано)
  • Forker — вариант из грамматического очерка Дианы Форкер (Diana Forker)
  • ЦӀадаса — латинские написания, связанные с текстами ХӀамзата ЦӀадасы
  • Claprot и Graham — исторические фиксации (Клапрот, Сирил Грэм)
